## ✦ TENTANG ASCHI BOT

**ASCHI BOT** (`@ASCHIASCHENBOT`) adalah bot Telegram multifungsi resmi dari **ASCHEN EVENT ORGANIZER**. 

Pada pembaruan ini, seluruh menu hidangan (makanan, dessert, dan minuman) telah diverifikasi memiliki foto asli resolusi tinggi yang sesuai dengan nama menunya, serta kategori **Minuman (Drinks)** telah tersedia lengkap untuk seluruh kategori hidangan: **Indonesian Food 🇮🇩**, **Korean Food 🇰🇷**, dan **Foreign Food 🌎**.

- 100% foto asli resolusi tinggi dari Unsplash dan Wikimedia Commons (berlisensi legal dan bebas hak cipta).

## 🔄 CARA MENJALANKAN BOT 24/7 (SELALU HIDUP)

Untuk memastikan bot berjalan terus-menerus tanpa henti (Keep-Alive):

### Opsi 1: Menjalankan di Windows (Lokal / Laptop)
1. **Jalankan dengan Supervisor (Auto-Restart jika error):**
   - Cukup double-click `start_bot.bat` atau jalankan:
     ```bash
     python watchdog_runner.py
     ```
2. **Jalankan di Background (Tanpa Jendela Terminal Terbuka):**
   - Double-click file `start_hidden.vbs`. Bot akan berjalan di latar belakang secara hening.
3. **Otomatis Hidup Setiap Windows Dinyalakan (Auto-Boot):**
   - Double-click file `install_windows_startup.bat`.
   - Bot akan otomatis aktif setiap kali komputer/laptop dinyalakan tanpa perlu dijalankan manual!
4. **Menghentikan Bot:**
   - Double-click `stop_bot.bat`.

### Opsi 2: Menjalankan di Cloud VPS (24 Jam Non-Stop Tanpa Laptop)
Agar bot tetap aktif meski laptop dimatikan:
1. Sewa VPS Linux Ubuntu/Debian (contoh: DigitalOcean, IDCloudHost, DomaiNesia, Biznet Gio, dll).
2. Upload folder bot ini ke VPS.
3. Jalankan script instalasi otomatis:
   ```bash
   chmod +x deploy_vps.sh
   ./deploy_vps.sh
   ```
4. Bot akan langsung terpasang sebagai **Systemd Service** dengan status `Restart=always` (otomatis hidup kembali jika server restart atau jaringan terputus).
